# Internal Workings

This project is a Retrieval-Augmented Generation (RAG) system designed to answer user questions based on a set of documents. Below is an overview of the key components:

### 1. **Domain Layer**
   - **Abstract Classes**: Defines the base interfaces for core functionalities, such as `BaseAgent`, `BaseLLMClient`, `BaseQuestionClassifier`, and `BaseAnswerGenerator`.
   - **Document Representation**: The `Document` and `EmptyResponse` classes define the structure of documents and empty responses.

### 2. **Use Cases**
   - **Agent**: The `Agent` class orchestrates the workflow by classifying the question, retrieving the relevant document, and generating an answer.
   - **Classify Question**: The `QuestionClassifier` matches a user question to a document based on predefined mappings.
   - **Answer Question**: The `AnswerGenerator` uses a language model to generate an answer based on the question and document context.
   - **Build Knowledge Base**: The `build_kb` function populates the vector store with documents (not yet implemented).

### 3. **Infrastructure Layer**
   - **Vector Store**: A simple in-memory store for documents, with methods to add and query documents.
   - **LLM Client**: The `LLMClient` integrates with LangChain's OpenAI client to generate responses from a language model.

### 4. **Interfaces**
   - **Gradio UI**: Provides a user-friendly interface for interacting with the system.
   - **CLI**: Placeholder for a command-line interface (not yet implemented).
   - **Document Loader**: Placeholder for loading documents from external sources (not yet implemented).

# Dependencies

The project uses the following dependencies, as specified in `pyproject.toml`:
